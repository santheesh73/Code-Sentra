# java-shop-api

A shop API in Java with Spring Boot.

## Features

- List products: `GET /api/products`
- Product details: `GET /api/products/{id}`
- Checkout with discount codes: `POST /api/checkout`
- Export orders as CSV: `GET /api/orders/export.csv`

## Setup

```sh
./mvnw spring-boot:run
```
